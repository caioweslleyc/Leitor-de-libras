Libras reconhecida pela câmera, em português.

Um protótipo Web que usa a câmera para encontrar a sua mão, transformar o gesto em números e mostrar a palavra correspondente na tela.

Esta é uma versão intermediária: o sistema reconhece uma quantidade pequena de gestos, que podem ser adicionados e removidos na própria página. Ele não substitui um intérprete humano.

Começar Nosso GitHub

Como funciona

  1. Câmera captura o gesto.
  2. MediaPipe encontra 21 pontos da mão.
  3. Modelo (scikit-learn) escolhe qual gesto é.
  4. Resposta aparece em português.

Equipe: Diego Vinicius e Caio Weslley
